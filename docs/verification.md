# 0.1.0 Alpha 验证记录

日期：2026-10-17。测试环境：macOS，Python 3.14。代码声明 Python 3.11+，其他系统/浏览器组合尚未做完整实机验收。

## 公开版离线验证

- 281 项隔离测试通过；另完成前端 JavaScript 语法检查。
- 测试覆盖身份与授权检查、岗位过滤、历史变化、消息去重、未知结果不重发、回执判定、App Server 协议、停止状态、HTTP 同源/写入令牌及页面行为。
- 在禁用外部连接和子进程的独立启动探针中，默认入口使用 DemoTasks；未启用配置的真实模式被拒绝；演示工作区不能用于真实模式。
- 实际浏览器演示：收集 6 段虚构会话，产生 3 项可跟进、1 项需本人决定、1 项低薪跳过、1 项结果未知。跟进后得到 3 项本地模拟记录；再收集仍为 3 项，不重复增加。停止按钮成功终止后续处理。
- 离线演示和测试未联系真实招聘方，未上传附件，未发送邮件。模拟结果不使用真实送达标记。

## 来源实例已有证据

来源私有实例曾完整读取 77 个会话；实际文字和附件历史回执有可核验记录。最近完整收集没有可执行的新发送，所以不能把这些读取证据当作最近已真实发送或已全面稳定。

纯文字索要简历的新发送流程尚未完成完整实机验收。公开版把身份和资料参数化之后，也需要在新账号上重新验证，不能继承作者账号的发送能力结论。

邮件模块默认关闭，属于实验接入。公开测试仅验证构造的工具回执与去重规则，没有在新配置上验证 Gmail 发现、真实发送与回读。详见 [配置说明](configuration.md)。

## 发布检查

公开版本从明确的代码文件清单建立；未复制私有主记录、简历、会话、邮件日志、浏览器资料、代理配置、音色参考文件或上游下载脚本。公开文件与来源实例的公司名、岗位/会话 ID、消息/邮件 ID 做了交叉排查；截图和视频只使用虚构演示数据。

代码不包含旧常驻执行器和其安装脚本。默认发送和邮件授权关闭；开源测试版没有自动轮询、自动海投或平台验证码处理功能。

## 复现

```sh
python3 -m unittest discover -s workbench/tests -v
node --check workbench/static/app.js  # 可选前端语法检查
python3 run.py --data-dir .local/review-demo --port 8766
```

前两项验证代码规则，最后一项启动独立虚构工作区。真实模式另行配置并由账号本人确认；遇到平台验证、连接失败或无法核验的发送，保留记录并停止。
